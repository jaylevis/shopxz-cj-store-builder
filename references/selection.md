# 选品规则

## 门禁项（全部必须通过）

| 项 | 默认 | 说明 |
|---|---|---|
| 发往目标国 | 必须有可追踪物流 | CN 仓优先 CJPacket 系列，JP 仓用 JP-Sagawa；无合规物流即淘汰 |
| 时效 | CN 仓 ≤12 天，JP 仓 ≤5 天 | 取物流报价里的最大天数比较 |
| 库存 | ≥50 | 首变体，CN 或 JP 任一仓满足 |
| 图片 | ≥3 张 | 少于 3 张无法做合格商品页 |
| 变体数 | ≤12 | 过多变体导入与库存同步成本高 |
| 重量 | ≤1,500 g | 运费与利润可控 |
| 价格 | 2–40 USD | 低于 2 美元多为低质量，高于 40 美元客单价不适合起步 |
| 毛利 | ≥45% | 售价减到手成本（含运费）除以售价 |
| 禁用词 | 标题、描述、材质均不含 | 品牌、违禁品、供应商名，见 `assets/banned-keywords.json` |
| 排除类目 | 化妆品、保健品、医疗、成人、刀具等 | 日本药机法与 GMC 高风险类目 |

## 评分与多样性

通过门禁后按 `listedNum`（CJ 上架数，代表被其他卖家验证过）、毛利、是否日本仓、图片数打分；`select` 在叶子类目间轮询取样，避免 40 个商品都是同一款的颜色变化。

## CJ API 用量

每天 5 万积分。每个候选商品约 3 次调用（详情、库存、运费），日本仓商品多 1 次。`candidate_multiplier=3` 时 40 个目标约 360 次调用。积分低于 2,000 自动停止，续跑从 `candidates.json` 继续。

## 维护禁用词

品牌名与违禁品在 `assets/banned-keywords.json`；新增时用小写、按整词匹配。供应商名一律禁止出现在任何面向顾客的文本中。
